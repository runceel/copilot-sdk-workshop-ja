アプリを作り、役割の境界を理解する。

  • Copilot のセッションを作成・管理する。
  • エージェントの継続的な方針とタスクのデータを分離する。
  • 目的に合ったツールの連携方法を選ぶ。
  • 出力が客観的な要件を満たすことをコードで検証する。
  • プロンプトによる指示と、コードで強制する制御の境界を説明する。
